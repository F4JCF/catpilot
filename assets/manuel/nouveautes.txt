== 0.26.0 | 2026-10-27 | mode d'emploi
- Nouvel onglet « Mode d'emploi » (bouton de la barre des panneaux, touche F1, ou menu Aide) : le mode d'emploi complet du logiciel, avec sommaire, recherche et taille du texte réglable.
- Impression de tout le mode d'emploi ou du seul chapitre choisi (« Imprimer… », « Imprimer ce chapitre… »), et « Enregistrer en PDF… » (A4).
- Le dernier chapitre reprend les nouveautés de toutes les versions ; « Aide > Nouveautés de cette version » y mène directement.
- Le mode d'emploi est mis à jour à chaque nouvelle version.

== 0.25.4 | 2026-10-26 | sauvegarde du carnet
- À chaque fermeture du logiciel, le carnet de trafic (base et fichier ADIF), la main courante et les réglages sont copiés automatiquement dans Documents\CATPilot\Sauvegardes, dans un dossier daté (ex. 2026-10-26_23h15m02).
- Une nouvelle copie n'est faite que si quelque chose a changé depuis la précédente (QSO ajouté, modifié ou supprimé, main courante, réglages).
- Les 30 dernières sauvegardes sont conservées, les plus anciennes sont effacées.
- Menu Carnet : « Sauvegarder le carnet à la fermeture » (coché par défaut, décochable), « Sauvegarder le carnet maintenant » et « Ouvrir le dossier des sauvegardes du carnet ».
- Pour restaurer : fermer le logiciel, puis recopier carnet.sqlite (et main_courante.sqlite) d'une sauvegarde dans Documents\CATPilot.

== 0.25.3 | 2026-10-26 | carnet
- Nouvelle colonne « Mon indicatif » : l'indicatif avec lequel chaque QSO a été fait (F4JCF, F4JCF/P, FR/F4JCF/P…), repris des fichiers ADIF importés (STATION_CALLSIGN, sinon OPERATOR).
- Modifiable par double-clic sur le QSO, ou pour plusieurs QSO à la fois : sélectionnez-les, clic droit, « Mon indicatif pour ces QSO… » (utile pour un ancien carnet importé sans cette information).

== 0.25.2 | 2026-10-26 | import ADIF
- À l'import d'un fichier ADIF, CAT Pilot demande si le fichier a déjà été contrôlé.
  - « Oui » : tout est importé tel quel, sans recherche de doublons.
  - « Non » : les doublons (même indicatif, bande et mode à 3 minutes près, déjà dans le carnet ou répétés dans le fichier) sont écartés et présentés dans une fenêtre : cochez ceux à importer quand même, ou annulez l'import.
- Import beaucoup plus rapide pour les gros fichiers.

== 0.25.1 | 2026-10-26 | carnet
- Locator manquant : quand QRZ.com (sans abonnement), HamQTH ou QRZCQ ne donnent pas le locator, CAT Pilot le lit sur la page publique de QRZCQ.com (locator, latitude, longitude), sans compte.
- En dernier recours, pour une station française, le locator est celui du centre de sa commune (d'après le QTH, service public geo.api.gouv.fr), avec la mention « locator du centre de la commune ».
- Le département est alors trouvé d'après ce locator, et la petite carte place correctement le correspondant.

== 0.24.0 | 2026-10-25 | CAT Pilot fonctionne aussi sous Linux
- Nouveau fichier CATPilot-x86_64.AppImage : à rendre exécutable puis à lancer d'un double-clic, sans installation (Ubuntu 22.04 et suivantes, Debian 12, Linux Mint 21, Fedora…, 64 bits). Aussi en archive CATPilot-linux-x86_64.tar.gz.
- Sous Linux : ports /dev/ttyUSB0 (Enhanced, CAT) et /dev/ttyUSB1 (Standard, CW/PTT) reconnus ; message d'aide si l'accès au port est refusé (groupe « dialout ») ou si le port est occupé (ModemManager).
- Son, chute d'eau, modes numériques (FT8/FT4, RTTY, PSK31, SSTV), SDR RTL inclus. Annonces vocales par speech-dispatcher ou espeak-ng. TQSL (LoTW) trouvé dans /usr/bin.
- Mise à jour automatique de l'AppImage depuis le menu « Mise à jour ».
- Windows : rien ne change.
